# Product demo assets

These assets show Monkex's October 21, 2026 source update, including the compact quota toolbar, reset times, credit balance and reset-card expiration details. They are used by the Chinese and English repository READMEs.

## Feature gallery · October 22, 2026

The READMEs use a compact, feature-by-feature gallery captured from the actual current shell. Each language has:

- `monkex-showcase-hero.{zh,en}.jpg`: desktop tree and grouped task board.
- `monkex-showcase-states.{zh,en}.jpg`: running, completed unread, and read states.
- `monkex-showcase-projects.{zh,en}.jpg`: two local project groups with stable color markers.
- `monkex-showcase-quota.{zh,en}.jpg`: expanded quota details, linked as a static alternative.
- `monkex-showcase-history.{zh,en}.jpg`: recent and older-history views of the same synthetic task set.
- `monkex-quota-focus.{zh,en}.gif`: a 6-second, 860 × 420 loop of the real quota area, cycling through summary, reset windows and card expirations.

All gallery stills are 1120 × 630. The viewports were framed directly from the rendered product; the UI text and controls were not redrawn by an image model. A local-only synthetic fixture supplied tasks, project names, balance, quota and dates, with unknown API operations blocked. Presentation labels outside the interface explain the features. These images show the interface and do not establish native desktop behavior or real-account integration acceptance.
