# Product demo assets

These assets show Monkex's October 21, 2026 source update, including the compact quota toolbar, reset times, credit balance and reset-card expiration details. They are used by the Chinese and English repository READMEs.

- `monkex-quota-demo.zh.gif`: Chinese animation, 540 × 960, 5-second loop.
- `monkex-quota-demo.en.gif`: English animation, 720 × 900, 5-second loop.
- `monkex-quota-demo.zh.png`: Chinese still with the quota details expanded.
- `monkex-quota-demo.en.png`: English still with the quota details expanded.

The interface is rendered from the product's shell with synthetic tasks and account values. No private conversations, account balance or credentials are included. The animation demonstrates the source version; public installer availability is described separately in the READMEs and Release notes.

Character and coin artwork was generated with ImageGen. These files retain the repository's rights terms.
